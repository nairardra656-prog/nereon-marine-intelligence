# NEREON — Marine Intelligence Systems

Final responsive frontend prototype for an AI-assisted side-scan sonar marine debris and anomaly detection platform.

## Demo login
- Email: `operator@nereon.ai`
- Password: `demo123`

## Included
- NEREON sonar-N brand mark across login, navigation and workspace
- Responsive login experience
- Dashboard and live sonar command centre
- Mission control and mission replay
- Detection review workspace
- Sonar image upload / AI analysis simulation
- AI detection explainability and analyst confirmation workflow
- Interactive-style mission map and detection hotspots
- Smart alerts
- AI model health monitoring
- Automated report generation workflow
- Analyst collaboration and evidence notes
- Accessibility profiles: normal, protanopia, deuteranopia, tritanopia, monochrome, high contrast
- Text scaling and reduced-motion mode
- Light/dark theme
- **NEREON AI assistant**: contextual guidance, instructions and question answering in the prototype
- **8-language switcher** in the top bar: English, Hindi, Arabic, Chinese, Spanish, German, Italian, French
- Language selection is saved locally for the next visit

## Notes
This is a self-contained frontend demo. Authentication, AI inference, telemetry, map data and report generation are simulated locally; a production build would connect these interfaces to secure backend services and real AI models.
